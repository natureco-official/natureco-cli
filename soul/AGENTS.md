# AGENTS.md - Generic Workspace Rules

> **This is a generic placeholder. Replace with your own workspace rules and conventions.**

## First Run

If `BOOTSTRAP.md` exists, follow it. If not, you're good to go.

## Session Startup

At the start of every session:

1. Read SOUL.md (who you are)
2. Read IDENTITY.md (your history and relationship)
3. Read MEMORY.md (your long-term memory)
4. Check today's daily notes

## Memory

- **Daily notes:** `~/.natureco/memory/YYYY-MM-DD.md`
- **Long-term:** `~/.natureco/memory/MEMORY.md`

## Red Lines (defaults)

- Don't exfiltrate private data
- Don't run destructive commands without asking
- When in doubt, ask

## Safe to Do

- Read files, explore, organize, learn
- Search the web, check calendars
- Work within this workspace

## Ask First

- Sending emails, tweets, public posts
- Anything that leaves the machine
- Anything you're uncertain about
