# NatureCo CLI — English documentation

This file is no longer maintained. **[README.md](README.md) is the English
documentation** and is kept current with every release.

`README_EN.md` was a second English copy of the README. Having two of them meant
one always fell behind: this file was still describing v5.6.x — 57 tools, 200+
models, 10 messaging platforms and the old personality/memory architecture —
months after v5.71 shipped with 91 tools, 133 models and 14 channels. A developer
who opened this file first saw a product that no longer existed.

The file is kept as a pointer so existing links do not break.
